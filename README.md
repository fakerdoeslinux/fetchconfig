# fetchconfig

A minimal, fast [fastfetch](https://github.com/fastfetch-cli/fastfetch) config with the small CachyOS logo.

## Preview

Uses `cachyos_small` and a compact module list: OS, kernel, packages, shell, WM, terminal, CPU, GPU, memory, uptime.

## Install

```bash
mkdir -p ~/.config/fastfetch
cp config.jsonc ~/.config/fastfetch/config.jsonc
```

Or test without installing:

```bash
fastfetch --config ./config.jsonc
```

## Requirements

- [fastfetch](https://github.com/fastfetch-cli/fastfetch) 2.x
